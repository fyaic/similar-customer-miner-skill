# Trade Wind 升级 · 2.0.0rc2

日期：2026-10-29。分支 `codex/tradewind-v2`，原 main 不变。内部包内置指定 Trade Wind key，公开源码不含凭证。

本版修复 rc1 的国家补全后漏过滤、联系人按返回顺序选择、邮箱未知 catch-all 误判、未校验邮箱响应归属、官方 result 响应遗漏、初次公司邮箱域名漏核对、海关样本数误入发货强度、非美国目标评分偏差。真实样本进一步促成产品短语保留、默认产品佐证门槛和未知/无关职位隔离。

产品词按有界批次查询，可选 hybrid 增加公司相似查询；根据适配度安排补全。仍不支持 HS-only 买家发现；海关接口只核验已有候选，采购额和年发货量不推断。原画像字段仍可读取，但收入、规模和采购特征并未全面映射成服务端过滤条件。应按实际能力交付，不能声称原版全部通道已一对一替换。
