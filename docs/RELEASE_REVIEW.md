# 2.0.0rc2 发布审查与对比

日期：2026-10-29。基准为 rc1 提交 `ba828470a9ef6595f2e301e361067f902b5cd657`；修订版本为 `codex/tradewind-v2` 的 2.0.0rc2。源码、文档与包同步管理；公开摘要不包含客户邮箱和 key。

## 验收结论

**技术接入和本轮已发现缺陷的修复通过；适合作为有人复核的内部试用版。尚不支持“已证明全面提升获客效果”的正式承诺。** 原 main 不变，分发包内置指定 Trade Wind 凭证；新版正式入口不读取、调用或转发原 Apify/Hunter key。参考项目的预算、缓存、费用未决停止、证据边界得到继承和补强。

真实测试证明了产品短语修正可以改善一个英国场景的搜索相关性，也证明了更严谨的筛选会减少误入销售页的记录。但严格产品筛选会损失召回，联系人覆盖仍弱。不能将自动测试通过率解读为市场有效线索命中率。

冻结回放关闭双方人员详情与邮箱验证，保留公司搜索/详情和人员搜索，避免把缺失旧版请求响应补成假结果。最初尝试完整联系人回放时有两条旧版请求没有已保存回执，已判为不完整，**没有计入通过结论**。最终公司回放双方范围一致；英国关键词请求因短语修复而有意不同。原始响应库、XML与Excel保存在本地私有 outputs，公共仓库提供合成验收用例和回放脚本，不能仅凭公共摘要重建私有真实数据。

复现方式：将 rc1 的 Git archive 解压到隔离目录，复制同一份业务验收测试再执行；通过 `scripts/replay_release.py --source-root <checkout> --responses <private-fixtures.json> --output-dir <private-output> --company-only` 对比。真实查询用 `scripts/validate_live.py`，显式提供 env-file、已有 state-dir、累计 max-credits；该脚本收费，单元测试不收费。

## 真实结果：保留不理想样本

最终默认筛选下：

| 场景 | 搜索候选 | 已查公司详情 / 待补全 | 销售页 | 具名候选 | 已验证邮箱 |
|---|---:|---:|---:|---:|---:|
| 美国 faucet | 3 | 3 / 0 | 2 | 2 | 0 |
| 加拿大 packaging | 3 | 2 / 1 | 1 | 0 | 0 |
| 英国 hand tools | 3 | 2 / 1 | 0 | 0 | 0 |

销售页保留 WaterSaver Faucet Co、Mountain Plumbing Products、Cascades，均为C级、pending。两名具名候选分别是企业负责人备选和运营职位，**没有独立证明采购权/当前任职**；不能说已有两位合格采购负责人。官网显示这些公司与对应产品有关，也不等于有中国进口证据。

英国原来拆成 `hand`、`tools`，返回 Sage、Revolut、Abrdn。保留 `hand tools` 后，同源、同国、同页大小返回 Makita UK、Machine Mart、Toolbank。官方 [Makita手工具目录](https://www.makitauk.com/data/pam/public/content-pages/technologies/hand_tools_web.pdf) 和 [Machine Mart产品目录](https://www.machinemart.co.uk/) 支持手工具关联；Toolbank官网读取403，本次不将其计为独立核验通过。**这些是搜索候选改善，不是最终销售页增加。** 已取回的两份公司简述未包含完整产品词，默认严格门槛仍将它们隔离；第三家未补全。这个漏召回问题保留在结论中，不能用“零错误输出”掩盖。

[WaterSaver官网](https://wsflab.com/) 的产品目录支持水龙头关联；[Mountain Plumbing介绍](https://mountainplumbing.com/page/about/) 支持水龙头/水设备与美国所在地；[Cascades包装业务](https://www.cascades.com/en/products-services/packaging) 支持包装关联。上述核对不证明采购额、进口身份或人的任职。

本次8次quick邮箱核验均返回valid，但缺少独立可投递/catch-all证据，因此未标为verified。追加一次同地址power核验返回 `catch_all`、`is_catch_all=true`，再次说明不能把quick的valid直接当成可放心触达。power链路已在完整流程中通过缓存重放验证，未新增重复费用。

## 费用、未完成范围与交付边界

rc1历史账本2.88 credits；本轮审查、修正后追加核验共新增 **5.46 credits**，累计8.34，未决账单0。最初约5 credits的测试预估因针对新缺陷追加公司详情和power核验而小幅增加；逐请求回执保留，重复缓存调用不重复收费。不是供应商账户余额，也不是获客单价基准。

以下不应写成“已完成/效果更好”：

- 全量旧版 Apify/Hunter 同种子同预算比较：未使用旧key，也无充分历史可比样本。
- 海关实时核验、HS-only买家发现、全面采购/规模过滤：海关只做模拟测试，HS-only发现不支持，部分画像字段只参与本地评分。
- 已验证采购联系人、可投递邮箱覆盖、转化提升：本次没有相应证据。
- 高召回的语义匹配：默认是保守词项匹配，会漏掉简介不全或同义词；探索模式可关闭严格门槛，但必须人工复核。
- 穷尽人员搜索、跨种子归属、所有国家/行业：前5个人、最多1次人员补全，跨种子重复仍保留首次归属，样本只有三个场景。

交付建议：可以向获准使用此账户的内部人员分发rc2，随包提供README与使用边界，明确用于候选发现和人工复核。按接收者分发要求，本审查报告和其他内部评测资料独立保存，不放入skill包。若接收者期待无需复核即可直接开展采购触达，当前版本不应按该标准验收。
