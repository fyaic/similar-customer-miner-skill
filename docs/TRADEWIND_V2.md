# Trade Wind 升级交付 · 2.0.0rc1

日期：2026-10-28。分支：`codex/tradewind-v2`。原 `main` 保留，升级可独立回退。内部 skill ZIP 带指定 Trade Wind key；公开 Git 仅保存源码、测试和不含客户资料的验证摘要。

## 改造内容

保留 Excel/CSV 种子输入、画像、种子/竞品排除、相似度/适配度/优先级评分、三页 Excel 和逐字段来源。在线流程接入 Trade Wind 公司搜索→公司详情→人员搜索→具备身份依据的人员补全。旧 Apify/Hunter key 不读取、不使用、不传 BYOK。供应商内部选择 Hunter 数据源仍通过 Trade Wind 结算。

沿用 sps-overseas-peers 的鉴权域名限制、禁止重定向、计费账本、精确请求缓存、未知费用停止、内部包凭证指纹和清单校验经验。API目录缩小至本技能需要的查询，不开放账户管理、无限额 Agentic 或其他无关能力。

公司/人员归属冲突不覆盖原身份；空人员记录不变成负责人；公共邮箱不绑定个人；供应商 guessed 邮箱降为0.35置信度并显示原始状态。候选默认为 pending。关键词筛选不能代替进口证据；HS、采购额和金额币种不从种子复制，也不从运费推算。

可选海关样本核验和邮箱验证已实现并进行模拟契约验证，本轮没有为这两条路径新增收费实测，不宣称已完整在线验收。

## 实测与局限

输入为美国市场 faucet 产品画像，种子 homedepot.com。本次 `similar_to` 探测只返回种子本身，因此有产品画像时优先关键词查询。查询得到 WaterSaver Faucet Co、Mountain Plumbing Products、PUR 三家公司。公司返回缺少国家时保留为空，补全后按提供的 HQ 字段记录，不把请求过滤条件当真实证据。

人员补全得到的三个具名候选邮箱被供应商标为 guessed；不是已验证可投递邮箱，也不能直接宣称是合格采购负责人。本次没有调用旧 key 做效果对照，不声称已证明转化率提高或全面优于旧版。作用是用一个 Trade Wind 账户接通可追溯的业务工作流。

最终计费与验收摘要见 [validation.json](validation.json)。实测原始回执和Excel仅保存在本地 outputs，不进入分发包或公共仓库。每次查询有 request_id/操作编号，已完成请求复用不产生新增费用。

## 分发与使用

内部 ZIP 安装时解压整个文件夹，保留 `.credentials/` 隐藏目录，运行 `scripts/tradewind_ops.py doctor` 可确认 bundled 配置。用户无需申请新 key；安装Python依赖后即可运行。包内不含旧 key、历史账本、日志、实测客户联系方式。每个文件有 SHA-256 清单，ZIP 另附校验文件。

默认本地累计预算2 credits、最多补全5家公司；因此较大名单可能因预算停止，仍交付部分结果并返回退出码2。需要扩大任务时明确设置 `--max-credits`，不通过换状态目录绕开未决收费。候选版仍需要更多产品/国家案例与人工业务反馈验证。
