# Trade Wind 升级 · 2.0.0rc3

分支 `codex/tradewind-v2-rc3`，基线标签 `v2.0.0rc2`（4d38dfe）。原 main 和 rc2 分支保持不变。

本版增加可见待复核队列、完整短语与显式别名匹配、官网产品证据复核入口。缺失简介不再被当作无关；国家和身份冲突仍隔离。业务角色、进口样本与采购身份独立展示。人员覆盖与邮箱验证算法未扩展，HS-only发现仍不支持。

README、SKILL、配置和双语工程文档同步管理。分发包只包含使用说明和运行所需文件，内置指定 Trade Wind key；工程文档、内部对比评测和测试摘要不随包。rc2审查归档至 releases/2.0.0rc2，当前审查见 [发布审查](RELEASE_REVIEW.md)。
