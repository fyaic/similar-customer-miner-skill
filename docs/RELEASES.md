运行版本来自 src/tradewind_core/__init__.py，发布时同步pyproject、default.yaml、SKILL、双语README、工程说明及当前评测。旧报告按版本归档，不改写成新版本结果。源码在Git；带key包只保存在本地受限目录，不作为GitHub发布附件。

发布顺序：运行行为回归与冻结数据回放 → 同步文档与当前评测 → 验证分发候选包 → 提交并推送新版本分支 → 创建不可覆盖的版本标签 → 从干净提交构建最终ZIP → 解压校验来源提交、哈希、key唯一位置及便携入口 → 更新本地交付指针。标签只标记源码，ZIP校验值记录在本地交付清单，避免将私有包上传Git。

回退时解压对应旧版本到新目录，不覆盖新安装；沿用原工作目录/账户账本，不通过删除账本绕过费用未决状态。分发ZIP仅带运行文件和用户文档，不附内部评测目录。
