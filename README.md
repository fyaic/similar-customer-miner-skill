# 相似价值客户挖掘 · Similar Value Customer Miner

> 把你**已成交的价值客户清单**，一键变成一批**长得像、买得起、联系得上的海外新买家名单**。

给外贸 / BD 团队：你手上有一批成交的高毛利客户，想快速找到"同行业、同 HS、采购规模接近、还能直接触达"的潜在新客户——这个工具自动帮你扒出来，并给每条线索排好**优先级**、补好**联系方式**、标注**可信度**。

---

## 它能为你做什么

- 🔎 **自动发现相似买家** —— 基于你客户的行业 / HS 编码 / 主营商品，从海关进口数据 + 全网搜索里扒出真实的美国进口商（是"新的、像你客户的"，不是你客户自己）
- 📇 **补全触达信息** —— 官网、决策人姓名与职位、邮箱、电话、社媒，尽量补齐，业务拿了就能开发
- 📦 **带进口实力** —— 显示每家的发货量 / 进口频次，谁在大量进口一目了然
- 🎯 **自动排优先级** —— 每条线索给一个"触达优先级分"，越靠前越值得先打
- ✅ **每个数据可溯源** —— 每个字段都标来源和可信度，不靠猜、不编造；估算值明确标注"估算"，绝不冒充真实采购额
- 📊 **开箱即用的表格** —— 直接给一张排好序、配好色、中文表头的 Excel，业务无需再整理

---

## 输出长什么样

![相似买家线索名单样例](docs/images/lead-list.png)

- **线索名单**（主表）：按触达优先级排序，公司名 / 官网 / 联系人 / 邮箱 / 发货量一行看全；橙色底色的"采购(proxy)"列会提醒你这是**估算值**而非真实采购额
- **评级说明**：A / B / C 表示这条数据的"可信度"，绿色越深越可信、越可直接触达
- 另有一张**完整明细表**，每个字段的来源、可信度、备注都能逐条追溯

---

## 三档评级怎么看

| 评级 | 含义 | 建议动作 |
|------|------|---------|
| **A** 🟩 | 关键信息齐全且可信 | 可直接触达 |
| **B** 🟢 | 主要信息可信，个别需复核 | 复核后触达 |
| **C** ⬜ | 信息还比较稀疏 | 先人工补全再触达 |

> 小提示：评级 = **数据可信度**，不代表该先打谁。真正的"先打谁"看名单第一列的 **优先级分**（综合了相似度 + 进口实力 + 联系方式完整度）。

---

## 数据从哪来（可放心使用）

- **海关进口记录**：谁在从中国进口什么品类、量有多大（来自 ImportYeti 提单数据）
- **全网公开搜索**：找到公司官网与基本信息
- **公开邮箱名录**：定位决策人的邮箱与姓名职位（来自 Hunter）

全部是**公开可得**的数据；每条线索都标注来源，不做登录态抓取、不碰个人隐私数据。

---

## 怎么开始用

1. 准备一份**客户清单**（Excel / CSV），至少要有 **目标行业** 或 **HS 编码**（有主营商品更好）
2. 交给工具跑，几分钟得到一张**线索 Excel**
3. 按优先级从上往下开发，绿色（A/B）的可以直接联系

---

## 大概多少成本

- **零成本也能用**：仅靠全网搜索 + 免费邮箱额度，就能跑出真实买家名单（含邮箱 / 联系人）
- **约 $83/月**（Apify + Hunter 入门档）额外解锁：按 HS 精确发现海关进口商 + 发货量验证 + 更多邮箱额度
- 更精准的商业海关库（真实采购金额）可二期接入
