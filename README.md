# 相似价值客户挖掘 · Similar Value Customer Miner

从一份**已成交的价值客户清单**出发，基于客户的行业 / HS 编码 / 主营商品，找出一批**画像相似的海外（美国）进口商**，尽量补上联系方式，并给每条线索标注来源、可信度和触达优先级，最终导出成一张结构化的 Excel。

面向外贸 / BD：用来把"已成交客户"扩展成"相似的潜在新客户"名单，作为开发线索的起点。它做的是**信息搜集与整理**，不替代人工判断——很多线索仍需你复核和补全。

---

## 已实现的功能

**1. 发现相似公司**
基于客户的行业 / HS / 商品，从两处找候选美国进口商：海关进口记录（ImportYeti）+ 全网公开搜索。会**排除你客户本身和行业龙头**，并做去重，保证是"相似的新公司"。

**2. 补充联系信息**
对候选公司尽量补齐官网、联系人姓名与职位、邮箱、电话、社媒。**覆盖率取决于公开数据**——不是每家都能补全，部门邮箱（如 info@）会和个人邮箱区分标注。

**3. 进口数据**
对部分公司能查到发货量 / 进口频次 / HS，以及一个**预估运费支出**。预估运费只是规模参考，会明确标注为估算，**不等于真实海关采购额**（真实采购额需要接商业海关库，本项目暂未接）。

**4. 相似度与优先级打分**
- `fit_score`：候选与目标画像的相似程度
- `priority_score`：综合相似度、进口实力、联系方式完整度，用于给线索排序

**5. 事实核查**
用规则对每条数据做一致性校验：采购额 ≤ 营业额 × 70%、公司存在性、联系方式可达性、HS 与区域一致性，输出 `passed / pending / failed` 状态。另外可选接入 Google Fact Check，检索**已发布的外部事实核查**作为补充引用——它只是佐证，不构成对营收或采购额的证明。

**6. 可溯源输出**
每个字段都带**来源、可信度（0–1）、备注**三项。估算值、推断值、未验证项都会显式标注，避免被当成确定事实误用。

**7. 结构化 Excel**
导出三张表：线索名单（精简、按优先级排序）、完整明细（全字段可审计）、统计与评级说明。中文表头，统一字体与配色。

## 评级与优先级

| 评级 | 含义 | 建议 |
|------|------|------|
| **A** | 关键字段齐全且可信 | 可直接触达 |
| **B** | 主要字段可信，部分需复核 | 复核后触达 |
| **C** | 信息稀疏或待验证 | 先人工补全 |

评级表示**数据可信度**，不代表触达顺序；触达先后看名单第一列的 `priority_score`。

> 说明：受限于免费数据额度，一次跑出的线索里往往有相当比例是 C 级（联系方式没补全）。可以先按优先级取前若干家，再针对性补全。

## 数据来源

- **海关进口记录**（ImportYeti 提单数据）：进口品类、发货量
- **全网公开搜索**：公司官网与基本信息
- **公开邮箱名录**（Hunter）：联系人邮箱与姓名职位

均为公开可得数据；每条线索标注来源，不做登录态抓取，不采集个人隐私数据。

## 使用前提

- 一份客户清单（Excel / CSV），至少包含**目标行业**或 **HS 编码**（有主营商品更好）
- 不配任何 API key 也能跑（靠全网搜索 + 免费邮箱额度）；配置数据源 key 后结果更精准
- 费用参考：免费可用；约 $83/月（Apify + Hunter 入门档）可解锁 HS 精确海关发现 + 发货量验证 + 更多邮箱额度
